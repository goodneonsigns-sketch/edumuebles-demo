# Edumuebles Industrial — sitio de demostración

Maqueta de sitio web para **Edumuebles Industrial, SRL** (Santo Domingo, República Dominicana),
fabricantes de mobiliario escolar, institucional y de oficina.

**Esto es una pieza de demostración, no el sitio oficial de la empresa.** Los datos marcados con
puntos rojos (licencias, cifras de capacidad, proyectos) son ejemplos pendientes de confirmar, y
los recuadros azules son marcadores donde van las fotografías reales.

Indexación desactivada (`noindex` + robots.txt).
